# Manifest aset PNG

Semua artwork CUA berasal dari desain maskot resmi milik CuanWeb3; gunakan referensi utama untuk konsistensi. PNG asli tersedia untuk implementasi dan konversi format web. Hero menggunakan latar ilustrasi, sedangkan sembilan aset lainnya memiliki kanal alpha, termasuk efek glow pada beberapa ilustrasi.

Referensi, jangan dipakai sebagai screenshot halaman: references/cua-official.png, references/ui-desktop-mobile.png, references/facebook-banner.png. Untuk misi atau Academy, gunakan welcome/grants/jobs sesuai konteks atau icon UI yang konsisten. Gunakan object-fit contain untuk aset karakter agar telinga, ekor, dan kaki tidak terpotong; crop hero hanya sesuai ruang yang tersedia. No fake data on UI; harga dan listing contoh pada referensi tidak nyata.
