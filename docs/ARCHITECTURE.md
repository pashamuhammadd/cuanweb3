# Arsitektur dan kontrak data

Next.js App Router, TypeScript strict, Tailwind, Supabase Auth/Postgres/Storage. Server components untuk halaman publik, client components hanya untuk interaksi. Postgres migrations dan RLS, bukan role checks di browser saja. Jalankan pnpm lint, typecheck, build serta smoke tests. Struktur folder mengikuti konvensi Next.js yang digunakan. Buat .env.example tanpa secret, README setup dan migrations yang dapat dijalankan ulang dengan aman.

## Routes
/, /peluang, /airdrop, /giveaway, /bounty, /jobs, /hackathon, /grants, /misi, /market, /belajar, /komunitas, /plus, /login, /akun, /akun/aktivitas, /akun/tersimpan, /akun/pembayaran. Detail gunakan slug unik; halaman admin /admin dan subhalaman opportunities, campaigns, submissions, sponsors, payouts, articles, users, subscriptions, settings. Public landing dan detail di-render SEO, canonical URL, metadata, sitemap dan robots; private akun/admin noindex. About, Contact, Privacy dan Terms tersedia dan sesuai praktik aktual.

## Data model konseptual
- profiles: id auth user, username unique, avatar, skill tags, locale, status; membership terpisah, hak admin disimpan server-side.
- opportunities: id, unique slug, category, title, summary, content, external_url, source_url, source_provider, external_id, reward_value/currency, reward_description, reward_type, requirements, tags, country/region, deadline_at, published_at, verified_at, state, image_path. Unique provider+external_id jika ada; canonical URL normalization untuk deduplikasi.
- sponsors, campaigns (opportunity_id, budget minor units, fee bps default 4000, reward pool, currency, funding state, start/end, campaign type), tasks (instructions, evidence type, ordinal), entries (campaign_id,user_id unique, state, reserved_until), task_submissions (entry/task unique, state, reviewer, feedback, evidence private). Simpan status transitional dan review history.
- draws (campaign unique id, eligibility snapshot dan hasil, audit record), winners (draw/user unique), payouts (ledger entries, amount minor units, currency, beneficiary, status, idempotency key unique), audit_events. Undian hanya peserta eligible setelah deadline; transaksi atomik, unbiased randomness dari CSPRNG, hasil tidak dapat diedit; jika diskualifikasi sah gunakan cadangan dari hasil yang tercatat. Jangan membuka fitur pembayaran/draw produksi sebelum persetujuan pemilik.
- bookmarks (user/opportunity unique), subscriptions (user, plan, status, valid_from/to, external_payment reference), notification_preferences, notification_jobs, articles, community_posts/reports, integration_sources, import_runs, market_snapshots.

## Integrations
Market provider: mulai dengan adapter CoinGecko atau penyedia resmi yang dipilih owner; pastikan dokumentasi, lisensi, rate limit dan API key terkini. API server-side cache, retry dengan backoff, timestamps, stale fallback terakhir yang valid dan error state. Jangan mengganti data kosong dengan angka palsu. Pakai USD/IDR yang didukung provider. Sumber peluang: adapter per sumber terverifikasi yang memang mengizinkan API/RSS/import. Gunakan sumber resmi, simpan provenance dan import sebagai draft untuk kurasi admin. Manual CRUD selalu tersedia; jangan mengarang API endpoint atau melakukan scraping yang dilarang. Jadwal sync dengan server cron, lock/idempotency, logs, backoff. Telegram/email notifications opt-in dan dapat dihentikan.

## Authorization dan integritas
Google OAuth lewat Supabase dengan callback yang valid, mapping provider identity, profil otomatis secara idempotent. RLS: publik hanya published listing, profil privat milik pengguna, submission/payout milik pengguna, write campaign/states oleh role admin server-side, bukti privat signed access sesuai hak. Role admin tidak dapat diubah pengguna. Simpan secret hanya di server. Validasi upload MIME/ukuran, URL dan input; sanitize konten rich text. Terapkan rate limiting yang sesuai, audit perubahan finansial, transisi state explicit. Unique constraints, transaksi atomic untuk slot/budget, pembayaran webhook terverifikasi dan idempotent jika kelak digunakan. Gunakan integer minor units. Jangan simpan private key, seed phrase atau data sensitif berlebih.
